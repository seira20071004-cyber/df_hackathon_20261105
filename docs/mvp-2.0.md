# Bridge Work 2.0 実装・検証

2026-11-07

## 実行

```powershell
npm ci
npm run demo
```

ブラウザーで http://127.0.0.1:3005/ を開く。別ポートは `npm run demo -- 3006`。Next.js の別の開発サーバーを起動している場合は、先に停止する。模擬AIモードは、架空のアカウント、ローカル簡易検査、模擬Gemini応答を使う。試演用のデータは `.bridge-work/hackathon-demo` に分離しており、通常の開発データは引き継がない。Googleの実API接続や実翻訳の検証には使えない。

### 試演手順

1. Linh でログインし、`Tôi không thể quét mã vạch. Tôi phải làm gì?` と入力。既存の類似ガイドが出たら、管理者に相談する。
2. 佐藤でログインし「対応する」を押す。日本語で「バーコードに汚れがないか目で確認してください。乾いた布で拭いてからもう一度読み取ります。商品名が表示されたら解決です。連絡先は demo@example.invalid です。」と返信する。
3. Linh が翻訳と原文を同じ吹き出しで確認して「Đã giải quyết」を押す。解決方法の追加記入は不要。
4. 佐藤が解決済みの相談から「マニュアルの確認へ」を開く。別コピーでメールアドレスが伏字になり、確認チェックを入れるまで生成できないことを示す。必要なら文字列の選択から追加で伏せる。
5. 「マニュアルを作成」で模擬Geminiが構造化手順を返す。管理者が内容・権限・公開範囲を確認して公開する。
6. Alex で同じ質問を検索する。公開版を開き、手順を進め、解決の記録を確認する。

## 実装済み

- スタッフのスマートフォン向けナビゲーション、相談ボタン、最近の相談、参照済みガイド、キーワード絞り込み。検索前でも管理者へ相談できる。管理者のPC向け確認画面は維持。
- 担当取得・引き継ぎ・履歴。管理者が最初の返信をする場合も担当を同じ更新処理で確定する。元のメッセージの送信者は変更しない。Firestoreモードではトランザクションを使用。
- 翻訳と原文を同じ吹き出しに表示。表示言語の訳がない場合は原文と翻訳再試行を表示。対応ブラウザーでは新規相談・返信の音声をテキスト化し、送信前に編集できる。
- 解決後に生成を開始せず、保護済みコピーを作る。原文と確認用コピーは分離。コピーで追加マスキングすると確認を取り消す。追加回答も保護・再確認してから生成する。認証情報を検出した場合や必須検査が利用できない場合は生成しない。
- 既存の4工程、根拠ID、編集・承認・公開制限、A4出力、条件分岐、ステップ閲覧を維持。全体表示で通過した経路を強調。解決できない場合は元の相談、参照ガイド、通過した経路を確認・編集してから送信できる。表示しただけの最後の手順を実施済みとは扱わない。
- FirebaseのGoogleログイン、組織作成・参加、招待発行のコードを追加。サーバーがFirebase IDトークンのGoogleプロバイダーと検証済みメールを確認する。新規組織の作成者のみ管理者として登録し、招待参加はスタッフに固定する。招待コードは乱数を使い、ハッシュのみ保存。期限と使用上限をトランザクション内で検査し、アカウント登録と同時に使用回数を消費する。

## 本番の接続設定

1. Firebase Authentication で Google プロバイダーを有効にし、アクセスするドメインを承認済みドメインに登録する。アプリの公開Web設定は `FIREBASE_PROJECT_ID` と `FIREBASE_WEB_API_KEY`、有効化は `BRIDGE_GOOGLE_SIGN_IN=true`。Google写真の初期表示は認証済みプロフィールから取り込む。表示名と使用言語はアプリの設定で変更する。
2. `BRIDGE_DEMO=false` とし、Firestore と実行用ADCを設定する。ブラウザーの直接読み書きは既存Rulesで拒否。新規組織は組織文書・現場文書・所属を作成する。既存組織で招待を発行する場合は、組織と現場の文書を確認する。
3. GeminiはVertex ADCまたはSecret Managerの既存設定を使う。DLP実接続は `BRIDGE_SENSITIVE_PROVIDER=google-dlp`、`BRIDGE_DLP_PROJECT` と対応IAMを設定する。厳格モードでは検査できなければ停止する。
4. 構成を確認後、実Firebase・DLP・Geminiの疎通と本番ビルドを検証する。今回はクラウドの設定変更・課金・外部デプロイを実施していない。

公式資料：[FirebaseのGoogleログイン](https://firebase.google.com/docs/auth/web/google-signin)、[Firestoreトランザクション](https://firebase.google.com/docs/firestore/manage-data/transactions)。
